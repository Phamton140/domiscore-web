# DomiScore Web

Este repositorio contiene el código fuente de la página web promocional, términos de servicio y política de privacidad de la aplicación móvil **DomiScore**.

*   **index.html**: Página web de presentación responsiva con diseño premium.
*   **privacy.html**: Política de Privacidad de la aplicación (requerida para la publicación en Google Play Store).
*   **terms.html**: Términos y Condiciones de uso de la aplicación.
*   **style.css**: Hoja de estilos compartida con un diseño premium y adaptado a dispositivos móviles.

Página publicada vía GitHub Pages en: `https://phamton140.github.io/domiscore-web/`
